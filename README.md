#  AI Flood Prediction System

An intelligent flood risk assessment system using Machine Learning and
domain-knowledge hydrological scoring, built with Python and Streamlit.

---

##  Project Structure

```
Flood-Prediction-System/
├── dataset/
│   └── flood_data.csv              ← India flood risk dataset (10,000 rows)
├── model/
│   └── train_model.py              ← Training pipeline + chart generation
├── saved_model/
│   └── model.pkl                   ← Trained Random Forest (auto-generated)
├── app/
│   └── app.py                      ← Streamlit web application
├── images/                         ← Charts (auto-generated by training)
├── requirements.txt
└── README.md
```

---

##  Setup & Run

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Train the model
```bash
python model/train_model.py
```
This will:
- Load and clean the dataset
- Train a Random Forest Classifier
- Evaluate and print accuracy + classification report
- Save the model to `saved_model/model.pkl`
- Generate 5 analysis charts in `images/`

### 3. Launch the app
```bash
streamlit run app/app.py
```

## How Predictions Work

The system uses a **hybrid scoring approach**:

| Component | Weight | Description |
|---|---|---|
| Domain Physics Score | 70% | Real hydrological thresholds |
| ML Model Probability | 30% | Random Forest trained on dataset |

**Domain thresholds used:**
- Rainfall > 250 mm → extreme risk
- River Discharge > 4,000 m³/s → very high flow
- Water Level > 8 m → dangerously high
- Elevation < 500 m → flood-prone terrain

**Severity classification:**
| Probability | Severity |
|---|---|
| 0–30% | 🟢 LOW |
| 31–70% | 🟡 MEDIUM |
| 71–100% | 🔴 HIGH |
